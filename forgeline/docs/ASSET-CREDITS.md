# Asset credits and dependency notes

## Original identity

The ForgeLine Steel mark and wordmarks are original SVG artwork created for this coursework. The F is formed from three flange-like shapes. SVG source uses editable paths and text. Light/dark variants and a square mark are supplied. Arial/system sans-serif is used in SVG wordmark text; convert text to outlines in a vector editor if exact cross-system typography is required.

## Purchased theme and fonts

The Hubsteel 1.0.1 parent and Case Addons plugin come from the supplied package. Parent files are not modified. Retain the original license files and verify that the recipient's theme use is covered by the purchased license. Bundled third-party plugins do not imply separate premium update rights.

Satoshi Regular/Bold and Clash Grotesk Semibold are copied from the supplied theme's font assets. Keep the supplied `Licenses/FFL.txt` with the handover. No external Google Fonts request is needed by the ForgeLine design.

## Runtime and plugins

WordPress Playground CLI is an official WordPress local runtime. WordPress core, Elementor, and Redux are downloaded from official sources. Installed versions are recorded in the validation report. ForgeLine does not require Slider Revolution, Mailchimp, or an online shop for its page layouts.

The included custom child theme and ForgeLine Site Tools plugin are supplied as editable source. Third-party code and assets retain their original licenses.
